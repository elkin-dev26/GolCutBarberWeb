## Descripción
Aplicación web Full Stack funcional desarrollada en **2026** para la gestión de la nómina de barberos. Permite realizar operaciones CRUD (Crear, Leer, Actualizar, Borrar). El backend está construido con Node.js y Express, la base de datos es MongoDB Atlas (en la nube) y el frontend es una interfaz premium (negro y dorado) con HTML5, CSS3, Bootstrap 5 y JavaScript.

## Instrucciones para Ejecutar el Proyecto

### 1. Preparación
1.  Descargue y extraiga el archivo comprimido `.zip` en una carpeta local (ej: `C:\gol-cut-barber`).

### 2. Instalación de Dependencias
1.  Abra una terminal (Símbolo del sistema o PowerShell).
2.  Navegue a la carpeta `backend` del proyecto extraído:
    ```bash
    cd C:\ruta\a\su\carpeta\gol-cut-barber\backend
    ```
    *(Asegúrese de reemplazar la ruta por la ubicación real en su PC)*.
3.  Ejecute el siguiente comando para instalar las librerías necesarias:
    ```bash
    npm install
    ```

### 3. Iniciar el Servidor
1.  En la misma terminal (dentro de la carpeta `backend`), ejecute:
    ```bash
    npm run dev
    ```
2.  Verifique que aparezcan los mensajes de éxito en la consola:
    > `Servidor ejecutándose en el puerto 3000`
    > `Base de datos conectada con éxito a MongoDB Atlas`

### 4. Visualización de la Aplicación
1.  Abra su navegador web (preferiblemente Google Chrome).
2.  Ingrese a la siguiente dirección: `http://localhost:3000`
3.  La aplicación se cargará y estará lista para su uso.
